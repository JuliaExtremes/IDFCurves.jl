
# Description

The code in this tutorial enables to reproduce the results presented in several publications.
To run it, make sure that the following Julia packages are installed:

```@example
using CSV, DataFrames, LinearAlgebra, Random
using Distributions, IDFCurves
using Cairo, CairoMakie, CanadaMap, Fontconfig, Gadfly
```

The code in Section *Training-validation goodness-of-fit test* enables to reproduce the results of Paoli *et al.* (2026).
